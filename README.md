# Ostad Assignment 04 🚀

Hey there! 👋 Just a personal portfolio website I put together for my Ostad Assignment 04.

It's a clean, responsive single-page portfolio with a sleek dark theme built using **HTML** and **Tailwind CSS v4**. It showcases my background, skills, featured projects, and a quick contact section.

### 🛠️ Tech Stack
- HTML5
- Tailwind CSS (v4)

### 🏃 Quick Start
```bash
# install dependencies
npm install

# start tailwind in watch mode
npm run dev

# build css for production
npm run build
```
